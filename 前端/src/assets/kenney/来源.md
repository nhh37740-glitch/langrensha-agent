# Kenney 素材来源与修改说明

本目录的图片来自 Kenney 的 CC0 素材包，原始下载页面：

- UI Pack - Adventure：<https://kenney.nl/assets/ui-pack-adventure>（版本 1.1，2024-08-13）
- Skyboxes Space：<https://kenney.nl/assets/skyboxes-space>（版本 1.0）

许可：Creative Commons Zero（CC0 1.0），<https://creativecommons.org/publicdomain/zero/1.0/>。
两个素材包各自的原始 `License.txt` 已按原文合并保存在本目录 `LICENSE.txt`，并标明包名。署名 Kenney / www.kenney.nl 不是许可要求，这里主动保留来源。

## 实际使用与修改

| 本目录文件 | 原始文件 | 修改 |
| --- | --- | --- |
| `sky-mist.webp` | `skybox-space-band.png` | 裁切缩放为 960×640，灰度双色调映射为雾蓝/旧金，叠底色渐变与底部暗角，转 WebP（quality 84） |
| `sky-hyperion.webp` | `skybox-space-day.png` | 同上，映射为沙金/锈红 |
| `sky-threebody.webp` | `skybox-space-dark.png` | 同上，映射为冷蓝/近黑 |
| `sky-tidal.webp` | `skybox-space-nebula.png` | 同上，映射为海青/铜绿 |
| `frame-mist.webp` | `panel_border_grey.png` | 64→128 最近邻放大，双色调映射为雾蓝/旧金，保留透明中心，WebP 无损 |
| `frame-hyperion.webp` | `panel_border_brown.png` | 同上，映射为锈红/沙金 |
| `frame-threebody.webp` | `panel_border_grey.png` | 同上，映射为冷钢蓝/近黑 |
| `frame-tidal.webp` | `panel_border_brown.png` | 同上，映射为铜绿/纸白 |

上述裁切、调色、缩放与格式转换均属于对 CC0 素材的修改；未使用任何需登录或付费的 itch.io 素材。四个天空纹理与四个头像框纹理均由 `worldart.js`（封面）和 `scene.js`（Phaser）实际加载使用；纹理缺失或加载失败时由 CSS 渐变与 Phaser Graphics 兜底。
