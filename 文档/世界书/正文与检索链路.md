# 四世界正文与检索链路

日期：2026-10-26（北京时间）。关联 Issue：#72（并回指 #39—#41、#43、#57）。

## 1. 入口与单一维护源

- 运行时正文的**唯一维护源**：`src/langrensha/worldbooks/{mist,hyperion,threebody,tidal_archive}.py` 中的 `WORLDBOOK.entries`、`roles`、`guidance`、`personas` 与 `basis`。
- 可阅读视图：[四世界正文](四世界正文.md)。该文件由 `python -m langrensha.worldbooks._render` 从上述数据生成，不手工编辑；`tests/test_worldbook_docs.py` 校验生成结果与提交文件完全一致。
- 调研文档：[海伯利安](../调研/世界书/海伯利安世界书调研.md)、[三体](../调研/世界书/三体世界书调研.md)、[潮汐档案馆](../调研/世界书/潮汐档案馆世界书调研.md)、[原著要素索引](../调研/世界书/原著要素调研索引.md)。调研是来源与核对依据，不复制进运行时语料，避免“两份正文”各自演化。

## 2. 正文 → 可见条目 → 分块 → 出处

| 步骤 | 代码位置 | 实际行为 | 可核验结果 |
| --- | --- | --- | --- |
| 正文 | `src/langrensha/worldbooks/*.py` | 每个世界一个 `WORLDBOOK`；条目含 `id/title/text/visibility` | 生成视图逐条列出条目与可见性 |
| 可见条目 | `worldbooks.visible_entries(book, role)` | 先按当前世界与角色过滤：`public` 或角色在 `visibility` 中才进入后续索引；秘密条目不会进入其他角色索引 | 见 `tests/test_worldbooks.py` 与 `tests/test_worldbook_docs.py` |
| 组装文档 | `retrieval.query(..., "ask_world", ...)` | 将可见条目组装为 `{"source": entry.id, "title": entry.title, "text": entry.text, "category": "world"}`，再追加本人 `self:guide` | `sources[].source` 即条目 id |
| 分块 | `retrieval.build_chunks` / `split_text` | 按句读与换行切成不超过 300 字的块；块保留 `source`、`world`、`game`、`visible_to` 等元数据 | 同一 `source` 的多个块不会被改写为其他出处 |
| 排序 | `retrieval._rank` | 优先固定中文语义模型（`bge-small-zh-v1.5`，阈值 0.40）；模型不可用时回退词项检索 | 响应 `method` 为 `semantic_retrieval` 或 `lexical_fallback` |
| 返回出处 | `retrieval.query` 返回 `{"answer", "sources", "method"}` | 同一 `source` 的多个块去重为一个来源，最多 12 个来源；`sources[].text` 为命中的原文块 | 每条来源都能回到 `四世界正文.md` 的同 id 条目 |

补充：`mist` 沿用历史 id（`world:arrival` 等），其余世界使用 `world:<世界id>:` 前缀；生成视图与索引表保留这些 id，便于和检索结果逐条对照。

## 3. 实际检索命中样例

以下命令使用当前 `src`，以普通镇民/朝圣者/观测员/岛民（`villager`）身份、同一世界公开条目查询；结果由本地固定语义模型返回，未把秘密条目放入样例。

| 世界 | 查询 | 方法 | 前 3 个返回出处（id / 标题） |
| --- | --- | --- | --- |
| 雾钟镇 | 铜铃 执铃人 逐离 夜裔 | `semantic_retrieval` | `world:bell` / 雾钟镇·铜铃；`world:goal` / 雾钟镇·约定；`world:arrival` / 雾钟镇·入镇 |
| 海伯利安 | 伯劳 光阴冢 朝圣 世界网 | `semantic_retrieval` | `world:hyperion:planet` / 海伯利安·边境行星；`world:hyperion:tombs` / 海伯利安·光阴冢；`world:hyperion:camp` / 海伯利安·朝圣营地（原创） |
| 三体 | 三颗太阳 脱水 智子 黑暗森林 | `semantic_retrieval` | `world:threebody:sophon` / 三体·智子锁死；`world:threebody:three_suns` / 三体·三颗太阳；`world:threebody:wallfacer` / 三体·面壁计划 |
| 潮汐档案馆 | 潮汐档案馆 生民册 潮窗 退潮密室 | `semantic_retrieval` | `world:tidal_archive:arrival` / 潮汐档案馆·低潮门；`world:tidal_archive:wardens` / 潮汐档案馆·潮册监；`world:tidal_archive:tide` / 潮汐档案馆·潮钟与潮窗 |

复现命令（在仓库根执行，使用已安装 `.[rag]` 的环境）：

```bash
python -c "from langrensha.retrieval import query; v={'game_id':'doc-check','seat':1,'role':'villager','round':3,'events':[],'worldbook':'threebody'}; r=query(v,'ask_world',{'question':'三颗太阳 脱水 智子 黑暗森林'}); print(r['method']); print([s['source'] for s in r['sources'][:3]])"
```

## 4. 本次核对与修正

- 海伯利安：按《海伯利安世界书调研》第 4—5 节修正高/中等级事实与译名，包括世界网/环网、鲸逖中心（鲸心）、议院、技术内核、远距传输器（含军用在建）、军部与奥林帕斯指挥学校、圣徒兄弟会/巨树之舰/尔格、毕库拉/特斯拉树/十字形、末日赎罪教派与“一人得愿”的传说边界、七名朝圣者名单、领事身份与时间要塞营地。
- 三体：按《三体世界书调研》第 4 节修正拯救派目标、末日战役与星舰地球舰船因果、归零者与回归运动的区分、干仓、破壁人执行者、太阳系防御系统、章北海职务、智子数量与“再送往地球”、宇宙社会学公理、黑暗森林打击主体、ETO 游戏用途，以及秘密条目的改编边界。
- 雾钟镇：本项目原创设定，沿用 `content.py` 已发布文案；未引入外部小说情节，未把规则改编写成原著事实。
- 潮汐档案馆：原创虚构世界；本次只做正文呈现与链路核对，不新增未标注的“事实”。事实灵感与逐条来源仍见其调研文档。
- 秘密条目：全部是游戏改编，运行时只在对应角色可见；生成视图将其单独分组并标注可见角色，不表示它们在公开目录或玩家视图中可见。

## 5. 隔离与验收

- 世界隔离：未知世界 id 由 `get_worldbook`/`_worldbook_for` 拒绝，不回退到其他世界；`ask_world` 只从当前世界的可见条目与本人指导组装文档。
- 角色隔离：`visible_entries` 先过滤再建块；公开查询不会返回秘密条目。测试覆盖海伯利安狼人秘密、三体/潮汐/雾钟镇各世界，以及“公开查询只返回本世界来源”。
- 正文一致性：生成文件与 `WORLDBOOK` 完全一致；每个条目原文经 300 字切块后拼接仍等于原文，且块 `source` 不变。
- 未编造：无法从调研或原创设定确认的内容保留“不确定/推断/传说/未核实”措辞；不把续作或影视设定混入第一部/三部曲边界。
