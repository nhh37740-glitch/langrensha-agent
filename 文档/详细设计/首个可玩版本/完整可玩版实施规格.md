# 完整可玩版实施规格

日期：2026-10-23。依据：用户最新明确要求“完成剩余功能”“无人值守”；关联 #1、#3、#4、#5、#6 及完整交付 Issue。该授权扩展此前 v0.2.0 的演练范围，本文件成为完整版本实施依据；既有版本说明保持历史原貌。

## 范围及归属

游戏对局模块新增独立的完整规则状态机 `full_game.py`，保留旧演练兼容性。完整局包括发牌、全部夜间技能、警长、放逐和平票、亮牌、遗言、自爆及胜负。服务层负责原子持久化、去重和受信身份；智能玩家扩展既有 LangGraph 原生工具循环，加载独立人格及身份指导。检索辅助模块先生成权限视图再召回世界书和事件，提供原文出处、玩家摘要与可编辑建议。网页模块采用 Phaser 场景与 HTML 操作及辅助面板；Web API 只认证真人会话，不公开主持快照或指定操作者入口。

## 本次工程采用的裁定

以下依据现有公开规则及最新无人值守授权选择，属于助手实施决定，**不标记为用户逐项确认**。规则版本固定为 `mist-v1`，后续更改须版本化并补迁移。

- 12 人预女猎白、狼刀个人票唯一最高者生效；平票或无人投票无袭击，允许袭击狼队及自己。
- 夜序：狼队、女巫、预言家；夜间死亡天亮同时结算。女巫存活时每夜知道袭击目标；不可自救，每夜至多一瓶药；毒药可指定自己。预言家不得查自己及连续两夜同一人。猎人夜间仍先完成其状态等待，毒杀不能开枪。
- 首次警长竞选先于死讯，尚未宣布的夜间遇害者仍参与。报名、竞选发言、退出选择、未上警者投票；退水者不投票。一名候选人自动当选；平票者再发言，再次平票或无票无警长。警长末位发言、放逐票权 1.5。
- 选举与放逐选票提交后先仅本人和主持可见，票齐才公布每人的选择与计票，避免顺序请求泄露同时投票结果。放逐首轮可投任意存活玩家（含自己）；平票者发言、其他有票权者重投；再平票或无票无人出局。白痴可主动亮牌免首次放逐，永久失去选举和放逐票权；弃权则接受死亡。已亮牌后不再免死。
- 夜间多人同时死亡先统一更新存活，再判胜负；所有狼人出局好人胜、所有平民或所有神职出局狼人胜；同时满足双方条件为平局。胜负优先于所有死亡触发技能，避免最后神职开枪逆转。猎人符合条件才开枪，之后处理警徽及遗言。
- 首夜死亡及白天死亡有遗言，后续夜晚无遗言；开枪造成的死亡依开枪发生的昼夜归属。自爆者有一次遗言，自爆公开行动并亮明夜裔身份，取消当天正常发言、投票，先公布尚未公布的夜间死讯与死亡效果，再进入下一夜。警徽产生前第一次自爆暂停竞选，次日重新报名恢复竞选（避免遗留报名资格歧义）；第二次自爆永久无警长。
- 死亡后可旁观后续公开事件；私人频道截止死亡事件（死亡后已授予的本人死亡技能结果仍可读）。身份在结束前继续暗置；结局公开全体身份用于复盘，但不公开他人的私人对话、药剂明细或 AI 审计。已死亡狼人不再收到新狼队信息。主持审计始终不经玩家 API 返回。
- 旧版演练独立保留，不是完整局入口。所有真人/AI 行动共享同一完整规则裁定、版本检查及请求去重；检索不消耗行动且不改变版本。累计星兆等已知技能事实单独保留，不随近期上下文裁剪遗失；仍须按当事人权限读取。

## 接口、运行与验收

Web 采用 FastAPI/Uvicorn；启动时加载服务器 `.env`，DeepSeek 密钥从不返回网页。首次入场使用服务器访问口令（远程部署必须配置），之后用高熵 HttpOnly/SameSite cookie 会话绑定唯一真人座位，会话摘要持久化。写请求要求同源；不接受客户端 actor、role 或主持权限。每次推进至多运行一个 AI 窗口，服务器串行锁防重复，浏览器可暂停自动推进；请求超时不导致重复执行。刷新可恢复正在玩的局，关闭页面停止发起新 AI 推进。AI 思考轮数可配置，不设置游戏行动倒计时。

前端通过受限 API 获得自己的身份、可见事件、合法操作及目标，不渲染内部事件 JSON、工具审计或主持数据。世界为“雾钟镇”：场景层日夜雾景，人物层十二位不同的职业人物与动作，能力层根据可见生效结果播放查验光、药剂涟漪或猎枪闪光；他人私有技能不得在普通视角播放。
