# 首个可玩版本的角色工具定义

日期：2026-10-23（北京时间）。状态：**原始工具草案，保留历史描述**。实际完整工具及裁定见[完整可玩版实施规格](../完整可玩版实施规格.md)和对应源码；本轮已授权完整实现。用户要求每次 AI 行动都按当前剧本、游戏身份和阶段提供工具，并提出代理复用与等待时间的问题；AI 与真人都能按各自权限调用 RAG 检索工具；目前不写代码。本文细化[首个可玩版本详细设计](../详细设计.md)，角色限制参照[预女猎白规则调研](../../../调研/狼人杀规则/十二人预女猎白标准局规则.md)。下列工具名称用于内部设计，不能直接作为玩家看到的游戏台词或界面文案；玩家端按剧本世界观表达，具体用语留到编码阶段确定。

## 每次启动代理时

后台先确定剧本、座位、游戏身份、虚拟人格、当前阶段及该玩家可见的历史，再准备**本次独立的决策上下文**，只提供本次允许的工具。数据包带该玩家可见的近期对话原文与较早历史摘要，更多原文由 RAG 按需取回；不把整局所有对话无差别塞入模型。通用发言和投票工具按阶段提供；查验、药水、夜袭等工具按“剧本中的游戏身份”提供；RAG 检索工具按该玩家的信息权限提供。AI 可在一次循环中先多次检索，再调用行动工具。虚拟人格和技能资料帮助判断，但不能增加工具权限。模型连接、无状态执行组件和相同工具配置可以复用；代理对象只有在权限与记忆能可靠清空并重新装配时才复用。下一次仍从对局记录构造上下文，不依赖旧循环的隐藏记忆。

对局编号、实际操作者、身份、阶段、行动窗口和对局状态版本由后台绑定，**不接受 AI 在参数中自称其他玩家或修改身份**。目标座位均为 1～12 的整数；后台还需检查目标是否符合当前技能规则。每个行动窗口最多接受一次生效行动：后台原子确认本次提交，同一请求的重试返回已记录结果，同窗口的不同请求被拒绝；状态已推进的过期调用也被拒绝，不能重复消耗药剂或产生第二个结果。行动工具成功才写入生效事件；检索工具只返回资料，不改变对局状态。越权或无效调用返回拒绝原因，不改变对局。模型只说“我查验 3 号”不算行动，必须发起对应工具调用。

## 一次代理循环怎样结束

1. 游戏推进到某位 AI 的决策窗口时，后台读取该玩家有权看到的对局记录，装入本剧本、本身份、本阶段允许的工具，再启动本次代理循环。**公开发言、狼人私聊和夜间查验结果分别按权限提供**，不能把主持人的完整记录交给代理后靠提示词保密。
2. 代理可先调用检索工具了解世界背景或可见历史；狼人处于交流窗口时也可使用狼队私聊。检索和私聊本身不替代该窗口最终要做的选择。代理可依据返回内容继续判断。
3. 代理调用本窗口允许的一个结束性工具，例如查验、用药、夜袭、发言、投票或“空行动”。后台再次核对真实操作者、阶段、目标、次数和资源，合法才记录效果；无效调用只返回原因，不推进阶段。每次模型生成一次回复或工具调用决定，计为一个思考轮；工具结果后再次请求模型，计入下一轮。每个行动窗口的最大思考轮数由配置提供，不设置用时计时；达到上限仍无合法行动时，后台按真人同阶段的弃权结果结束本窗口。
4. 后台只把该玩家有权知道的结果返回给代理，再由游戏流程决定是否进入下一玩家或结算。此窗口结束后释放本次上下文；同一玩家下次行动时从保存的记录重新装载。一次循环中多次检索与一次合法行动的调用记录均可供验收核对。

例如，预言家可以先检索白天公开发言，再调用“查验”选择目标；后台把查验结果仅返回给预言家。女巫可以先查自己可见的记录，再在“解药”“毒药”“空行动”中选择一个。狼人可以先查己方私聊、发送私聊，再各自提交夜袭票；票数最高的目标成为狼队选择，最高票并列则当夜不袭击。以上只是调用过程示例，不增加角色能力。

弃权是后台可直接记录的同阶段结果，不要求超出轮数的 AI 再调用一次工具：发言窗口记为沉默，竞选报名窗口记为不报名，投票窗口记为弃票，夜间技能与狼队夜袭票记为不使用或不投票，警徽移交窗口不指定继任者则撕毁警徽。真人主动选择弃权走同一规则；被动规则裁定仍由主持自动完成。自动弃权记录“思考轮数用尽”原因，正常弃权只记录玩家选择。复用方案的验收还要检查：同一运行组件先服务狼人、再服务平民时，平民既拿不到狼队工具，也检索不到狼队私聊或投票结果；同一玩家跨阶段行动时，只能调用新阶段的工具，且思考轮数不超过配置上限。

## 阶段通用工具

这些工具不属于某个特殊身份，只在当前阶段向有行动资格的代理提供。真人在界面做同类行动，也走相同的后台规则。

| 工具 | 参数 | 后台操作 |
| --- | --- | --- |
| 发言 | 发言内容：非空文字 | 确认轮到该玩家后记录公开发言，并结束本次发言机会；警长竞选发言也使用此工具。 |
| 放弃发言 | 无 | 在发言窗口记录该玩家选择沉默，并结束本次发言机会。 |
| 投放逐票 | 目标座位：1～12 | 验证目标仍有被投票资格、操作者有票权且未投过；记录选票，票齐后按警长权重与平票规则结算。 |
| 弃票 | 无 | 在警长或放逐投票窗口记录不投票，防止同一轮重复投票。 |
| 参加警长竞选 | 无 | 仅在报名阶段登记候选资格。 |
| 退出警长竞选 | 无 | 仅允许已报名且尚未完成选举的玩家退出，并按规则取消其本次选举票权。 |
| 投警长票 | 目标座位：1～12 | 仅允许有选举票权的玩家投给有效候选人；记录选票，票齐后按平票与重投规则产生或不产生警长。 |
| 移交警徽 | 目标座位：1～12 | 仅在现任警长出局、规则允许移交时，把警长资格交给有效存活玩家并记录事件。 |
| 撕毁警徽 | 无 | 仅在现任警长出局、规则允许时取消警长资格并记录事件。 |
| 空行动 | 无 | 在身份技能或狼队夜袭投票窗口记录“本次不使用／不投票”，不消耗药剂等资源，也不产生技能效果，然后结束该行动机会。狼人不投票记入仅狼队和主持人可见的历史。AI 主动选择时是工具调用；达到思考轮数上限时由后台记录同样结果。 |

## 预女猎白身份专属工具

“夜袭”属于**预女猎白剧本中的狼人身份**。今后其他剧本即使也有“攻击”，仍应依据那个剧本的身份规则单独定义效果，不能因为名称相同就共用权限。

| 身份与工具 | 参数 | 后台操作 |
| --- | --- | --- |
| 狼人：狼队私聊 | 内容：非空文字 | 在允许狼队交流的阶段记录消息，仅向狼人和主持人开放；不作为公开发言。 |
| 狼人：夜袭 | 目标座位：1～12 | 检查夜晚与狼人身份，每名有行动资格的狼人提交一票或选择空行动；汇总后唯一最高票目标成为当夜袭击对象，最高票并列或无人投有效票则无人被袭击。每名狼人的投票、弃权及计票结果写入仅狼人和主持人可见的狼队历史，供后续对话与 RAG 检索。 |
| 狼人：自爆 | 无 | 仅在允许自爆的白天阶段立即使该狼出局，停止当天正常发言与放逐，并按首日警长竞选的双爆规则处理警徽及下一阶段。 |
| 预言家：查验 | 目标座位：1～12 | 检查夜晚、目标及本夜尚未查验；记录目标，私下返回“好人”或“狼人”，不返回具体职业。调研稿的“不可连续两夜查同一人”尚待规则基线核定。 |
| 女巫：使用解药 | 无 | 只对后台掌握的当夜狼刀目标生效；检查解药未使用、不可自救、本夜未用另一瓶药，记录解救并消耗解药。目标由后台确定，AI 不可改写。 |
| 女巫：使用毒药 | 目标座位：1～12 | 检查毒药未使用、本夜未用另一瓶药及目标资格，记录毒杀目标并消耗毒药；在夜间结算时确定死亡。 |
| 猎人：开枪 | 目标座位：1～12 | 仅在符合开枪条件的出局窗口执行；记录并使目标出局。被女巫毒死、或已达到全部神职出局条件时拒绝开枪。 |
| 白痴：翻牌免放逐 | 无 | 仅在被放逐的结算窗口亮明身份，取消此次放逐，保留发言权、失去后续投票权，并记录公开亮牌。 |
| 平民 | 无专属工具 | 夜晚没有身份行动；白天只接收符合阶段的通用工具。 |

女巫可收到“使用解药”“使用毒药”“空行动”三个互斥选择；选了其中一个便结束该夜的女巫行动。预言家、猎人等身份只在对应窗口收到自己的专属工具，同时可用“空行动”放弃本次主动能力。空行动不会替代投票时的“弃票”或发言时的“放弃发言”。

## 真人与 AI 共用的查询和检索工具

真人可在辅助入口使用；AI 可在自己的行动循环中调用。两者使用同类工具，但后台先按**当前调用者**真实身份和当时可见记录过滤，因此答案可能不同。检索不执行投票、技能或发言；AI 可利用检索结果继续判断。狼队私聊可供狼人检索，不进入普通玩家的检索结果。

| 工具 | 参数 | 后台操作与返回 |
| --- | --- | --- |
| 询问世界背景 | 问题：非空文字 | 只检索调用者有权看的剧本背景资料；返回回答及资料出处，资料不足时说明未知。 |
| 检索可见发言 | 查询文字：非空；目标座位、轮次范围：可选 | 先过滤权限，再找符合问题的公开发言；狼人还可检索己方私聊、夜袭投票及计票结果。返回片段、发言者或事件来源、轮次和出处。 |
| 总结指定玩家发言 | 目标座位：1～12；轮次范围：可选 | 先过滤权限，再检索该玩家的可见发言；返回摘要、逻辑线索及对应发言出处。 |
| 查看自身身份与任务 | 无 | 直接从对局事实读取调用者自己的身份及当下可见任务信息；它是查询工具，不用 RAG，也不透露其他玩家身份。 |

## 真人专用的发言提示

| 工具 | 参数 | 后台操作与返回 |
| --- | --- | --- |
| 生成发言提示 | 关注点：可选文字 | 依据真人身份、可见背景和发言记录生成可编辑的建议；标明依据，不自动替真人发言或调用投票、技能工具。 |

## 还需确认的裁定

猎人、白痴等临界胜负的准确结算顺序仍需在实施前依据剧本规则核定。用户已确定：狼队最高票并列或无人投有效票则当夜不袭击，狼队投票及结果进入仅狼队和主持人可见的历史；AI 思考轮数由配置项控制，达到上限未行动按真人同阶段规则弃权，不设计用时计时。工具调用记录会保存以便验收；玩家在游戏中或赛后能看到多少记录仍待确认。待定项不能通过提示词或模型自由发挥来补规则。
