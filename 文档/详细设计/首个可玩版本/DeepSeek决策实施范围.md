# DeepSeek 决策实施范围

日期：2026-10-24（北京时间）。依据：用户本轮指定 DeepSeek API 并要求继续无人值守；对应 #3 下的子任务 #10，依赖最小内核 PR #9。

本次只接入内核已经支持的狼队私聊、夜袭投票、白天发言和弃权，不补未核定的特殊角色裁定，不关闭整个 #3。用户已指定模型供应商；接口模型列表已实际返回 `deepseek-flash` 和 `deepseek-v4-pro`，默认使用前者，可通过运行配置调整。没有把模型列表或模型本身当作玩法依据。

LangChain 的 `ChatDeepSeek` 发起原生工具调用，LangGraph 管理每次独立行动的“模型 → 执行工具 → 再思考或结束 → 必要时后台弃权”。每次 `run` 使用新消息列表、固定行动窗口与人格，只复用无状态模型连接。每次请求重新读取已过滤的玩家视图，近期事件数量可配置；尚未实现较早记录的 RAG 与摘要，不声称实现完整历史检索。

工具白名单来自当前受信玩家会话；模型参数只有选择目标或发言，不接受操作者、身份、对局或窗口。每次行动提交绑定模型看到的版本，过期调用由规则拒绝，下一轮重建上下文。人物描述只影响表达，不改变身份和工具。每轮最多执行配置数量的工具，一次原生模型回复算一轮；最多 20 轮为工程上限，默认三轮，默认不启用扩展思考。达到上限未完成时，由后台执行与真人一致的弃权，并标注“思考轮数用尽”；网络/供应商失败时标注“模型不可用”。连接超时仅用于处理网络故障，不是玩法计时。

AI 调用的参数、接受或拒绝结果和终止原因仅写入主持审计。玩家视图不返回审计表，且不会保存或展示模型的私有推理。LangSmith 自动追踪在决策范围内关闭；密钥不进入提示词、错误正文、日志、GitHub 或 CI。真实接口验证手动运行，CI 仅用模型替身验证控制流和隐私，避免重复消耗密钥和付费调用。

此版本仍无完整对局、RAG、网页、服务器部署或完整角色工具。后续完整剧本接入时须替换演练调度并补齐其规则与验收。
