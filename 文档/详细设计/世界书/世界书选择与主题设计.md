# 世界书选择与主题设计

制定日期：2026-10-25。对应 Issue：#63。实施分支：`deepseek/issue-63`，基线 `a569ae3`。状态：分支内实现，待 PR、Codex 审查与现有 5 项 CI；v0.7.0 未发布、未打 tag。

## 1. 范围与用户结果

用户可在入镇页浏览并选择现有四本世界书：雾钟镇、海伯利安、三体、潮汐档案馆。每本展示程序化/素材封面、公开简介与角色称谓；进入对局后，玩家视图、AI 提示词、RAG 检索和 Phaser/CSS 视觉主题都跟随所选世界，刷新后保持一致。目录只含公开数据，秘密条目、身份指导、隐藏阵营和人物秘密不通过目录或图片泄露。

本设计按 2026-10-25 用户最新要求处理：当前仍是开发阶段，优先采用单一、清晰的接口和状态结构，不为旧版本对局保留重复兼容分支；“历史对局默认 mist”的旧验收项不再作为本单要求。用户同时授权 Codex 用 ChatGPT AI 绘图提供美术，DSH 负责接入、构建与浏览器验证。

## 2. 接口与状态

### 2.1 公开目录 `GET /api/worldbooks`

无需登录，返回：

```json
{
  "default": "mist",
  "worldbooks": [
    {
      "id": "mist",
      "name": "雾钟镇",
      "tagline": "……",
      "summary": "……",
      "glyph": "♜",
      "motif": "bell",
      "palette": {"sky": "#…", "mid": "#…", "accent": "#…", "paper": "#…", "ink": "#…"},
      "role_labels": {"wolf": "夜裔", "villager": "镇民", "seer": "观星者", "witch": "药师", "hunter": "守林人", "idiot": "守誓者"},
      "public_count": 4,
      "excerpt": "只取首条 public 条目，≤140 字",
      "scene": {"eyebrow": "…", "title": ["…", "…"], "subtitle": "…", "caption": "…", "chapter": "…", "footer": "…", "intro": "入镇欢迎语"}
    }
  ]
}
```

`worldbook_catalog()` 从世界书公开字段和 `presentation.THEMES` 重建响应，不导出 `entries`、`guidance`、`personas`、`basis`，也不导出任何非 public 条目文本。`motif` 固定为 `bell|tombs|signal|tide`。

### 2.2 建局 `POST /api/game`

- 请求允许 `{"role"}` 或 `{"role","worldbook"}`；缺省/null 采用 mist，未知或非法 id 返回 422，不落库。
- `GameService.create(..., worldbook=...)` 先校验注册表，再写 `state["worldbook"]`；`create_game`/`create_full_game` 同样接收并持久化该字段。
- 玩家视图（内核与完整局）返回 `worldbook`，作为后续表现层、AI 与检索的单一世界标识。
- `present(view)` 返回 `worldbook`、`worldbook_name`，并按世界切换人物公开姓名/描述/颜色、身份称谓、章节、行动标签、结局与私密视觉文案；缺失 worldbook 的坏视图只在表现层防御性回退 mist，不构成旧格式兼容路径。

### 2.3 AI 与 RAG

- `retrieval._worldbook_for(view)` 继续读取 `view["worldbook"]`；权限过滤先于切块/索引，秘密条目不会进入候选集。
- `ai.system_prompt` 继续按 `view["worldbook"]` 选择世界名、身份称谓、指导与首条 public 背景。
- `/api/advance` 的 AI Persona 改为从当前世界公开 `personas` 取对应席位；不再固定使用雾钟镇人物。
- 世界书不增加规则权限；身份、目标、工具仍由规则内核和工具 schema 决定。

## 3. 四套视觉主题

每套主题都有独立的材料、光线、封面图形、场景轮廓与动效，而不是同一套深色 UI 换色。调色板同时供 `GET /api/worldbooks`、`worldart.js` 封面与 `themes.css` token 使用。

| --- | --- | --- | --- | --- |
| 雾钟镇 mist | 雾蓝 `#0b1a21`、旧金 `#d8bd85`、纸白 `#e9dfc6` | 钟楼、拱门、雾带 | 钟楼广场、石阶、灯火、雾层；十二名披风旅人，Kenney 头像框 | 雾层漂移、灯火呼吸、月光 |

### 3.1 封面

`前端/src/worldart.js` 用 `renderCover(container, book)` 生成 `.world-cover[data-motif]`。封面由 CSS 渐变、程序化 SVG 图形、Kenney 天空纹理和可选的 AI 背景组成；所有 API 文本用 `textContent`/DOM 写入，不使用 `innerHTML`。四个 motif 各自绘制钟楼、冢体、监听站/天线、档案馆/潮线，选中卡同时展示 glyph、tagline 和公开条目摘录。封面图加载失败时保留渐变、SVG 与文字，不影响选择。

### 3.2 Phaser 场景

`前端/src/scene.js` 保持 `makeScene({reducedMotion}) → {update, setReducedMotion, destroy}` API，读取 `state.worldbook`：

- 纹理：Kenney 天空图、Kenney UI 头像框；潮汐使用 AI 低潮背景与 AI 档案员画像，按 `state.worldbook === "tidal_archive" && seat === 9` 绑定公开席位。
- 场景：四套天空/地面/建筑轮廓/环境粒子，人物仍只用服务器返回的公开人物颜色和公开姓名，不按隐藏身份着色。
- 动效：Phaser tween 驱动漂雾、时间波纹、信号扫描、潮线/纸页；`prefers-reduced-motion` 或运行期开关会暂停连续 tween，保留静态状态。
- 失败兜底：`loaderror` 或缺纹理时退回 Graphics 绘制，不阻断入镇、行动与刷新。

### 3.3 排版与交互

沿用现有宋体标题 + 无衬线正文，但按世界切换品牌名、英文副题、场景标题、章节、页脚与角色称谓；卡片采用非等宽、带切角的版面，避免通用 SaaS 卡片套件。选中的世界以边框、封面色与状态文案三重反馈；键盘可用 Tab/Enter 选择，方向键可在卡片间移动。390px 下卡片改为单列/可横向滚动，保证触摸目标与无横向溢出。

## 5. 信息权限

- 目录接口只输出公开表现数据；`public_count` 和 `excerpt` 只来自 `visibility == "public"` 条目。
- `present` 只输出当前玩家自己的身份、公开名单、已公开角色或狼队同伴；不输出其他玩家隐藏身份、秘密条目、身份指导。
- 人物画像按公开席位绑定；不会因为玩家抽到狼人/神职而切换图片或颜色。
- 调试能力不在本单范围；本单不新增向 AI 或玩家注入额外秘密的接口。

前端（Playwright，真实 Chromium + 真实 HTTP）：

- 四本世界可选，选择后请求体包含 worldbook，刷新后主题/文案/身份一致。
