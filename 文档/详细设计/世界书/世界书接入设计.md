# 世界书接入设计（最小版）

制定日期：2026-10-25。对应 Issue：#39。范围：世界书注册、角色可见性过滤、检索与 AI 提示词的最小接入；不含建局选择、前端视觉切换与完整剧本。

## 1. 目标与边界

- 新增 `src/langrensha/worldbooks/`，每个世界一个模块，模块暴露 `WORLDBOOK`。
- 保持默认世界“雾钟镇”（id: `mist`）与现有对局、现有测试不变。
- 本轮交付检索知识层接入：玩家视图可带 `view["worldbook"]`，检索与提示词据此切换；未带该键时仍用 mist。
- 不修改规则内核、不新增工具、不改变胜负条件；世界书条目不能增加权限。

## 2. 分层与依赖

`pyproject.toml` 的 import-linter 分层调整为：

```text
web / 入口
ai | assistant | presentation | service
retrieval | store | full_game
worldbooks
semantic | content | rules
```

`worldbooks` 只向下依赖 `content`（mist 适配复用既有常量），不依赖 `rules`、`retrieval`、`ai`、`service`、`store`。`retrieval` 与 `ai` 向上依赖 `worldbooks`。这样既避免在 `worldbooks` 中复制雾钟镇数据，也避免同层兄弟模块互相导入。

## 3. 接口

```python
WORLDBOOK = {
    "id": "hyperion",
    "name": "海伯利安",
    "basis": "来源与授权说明",
    "entries": [
        {
            "id": "world:hyperion:arrival",
            "title": "海伯利安·最后一支朝圣队",
            "text": "……",
            "visibility": "public",  # 或 ["wolf"]
        }
    ],
    "roles": {"wolf": "荆棘使徒", "villager": "朝圣者", ...},
    "guidance": {"wolf": "……", ...},
    "personas": [("名字", "描述", "#rrggbb")],
}
```

约束：

- 必填字段：`id`、`name`、`basis`、`entries`、`roles`、`guidance`、`personas`。
- 条目必填：`id`、`title`、`text`、`visibility`；id 唯一。
- 条目 id 命名空间：`world:<book id>:<slug>`。`mist` 为兼容既有来源，保留历史 `world:arrival` 等 id，是唯一豁免。
- `visibility` 为 `"public"` 或角色列表；角色必须属于 wolf/villager/seer/witch/hunter/idiot。
- `roles`、`guidance` 缺失键时安全回退 mist；`personas` 长度由各世界自定。
- 新增世界只需新增模块，`pkgutil` 自动发现，不改注册文件。

## 4. 注册与查询

`worldbooks/__init__.py`：

1. 用 `pkgutil.iter_modules(__path__)` 遍历同包模块，跳过下划线开头的私有模块。
2. 导入模块，读取 `WORLDBOOK`，执行字段、id 前缀、可见角色与重复 id 校验。
3. 建立 `id -> WORLDBOOK` 注册表；要求默认 `mist` 存在。
4. 提供：
   - `get_worldbook(id=None)`：默认返回 mist；未知 id 抛 `KeyError`。
   - `visible_entries(book, role)`：先按角色过滤，返回 public 与当前角色可见条目。
   - `role_name(book, role)` / `guidance_for(book, role)`：取世界内文本，缺失回退 mist。
   - `personas_for(book)`：返回人物列表。
   - `worldbook_ids()`：已注册世界 id，供测试与后续选择界面使用。

## 5. 检索与提示词流程

### 5.1 `ask_world`

```text
玩家视图 view
  -> 解析 view.get("worldbook", "mist")
  -> get_worldbook(id)；未知 id -> Rejected("unknown_worldbook")
  -> visible_entries(book, view["role"])   # 先过滤
  -> 追加 self:guide（当前角色身份指导）
  -> 语义/词项检索与排序
  -> 返回带 source 的结果
```

过滤发生在切块与索引之前；不可见条目不会进入候选集，因此不会被语义相似度带回。

### 5.2 `self_info`

使用 `role_name(book, role)` 与 `guidance_for(book, role)`；保留原有“座位 + 身份 + 指导 + 星兆事实”的返回结构与 `method: fact`。

### 5.3 AI 系统提示词

`ai.system_prompt(view, persona)` 使用：

- 当前世界书 `name`；
- 当前角色称谓与身份指导，标签为 `<book id>-v1`；
- 首条 public 条目的文本作为入场背景。

mist 默认输出与原提示词等价；未知世界回退 mist，保证对局不中断。真正的权限仍由工具 schema 与规则内核控制，提示词只提供叙事与身份说明。

## 7. 测试矩阵

| 用例 | 断言 |
| --- | --- |
| 自动发现与字段 | mist、hyperion 均注册；必填字段、角色、id 唯一性通过 |
