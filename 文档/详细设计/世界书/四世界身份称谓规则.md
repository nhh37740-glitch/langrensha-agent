# 四世界身份称谓规则

日期：2026-10-27（北京时间）。依据：[Issue #86](https://github.com/nhh37740-glitch/langrensha-agent/issues/86)及已合入四世界世界书。

## 命名规则

- 以世界内的群体、职能和仪式命名六种秘密身份，保持简短可辨；不使用通用狼人杀称谓作为游戏界面身份名。名称是本项目的世界观改编，不宣称原作人物具有狼人杀技能。
- 固定规则键 `wolf/villager/seer/witch/hunter/idiot` 与能力、次数、胜负和可见性不变；界面按当前世界翻译身份。公开人物姓名与职业和随机秘密身份分开，不能由画像或职业推断阵营。
- `WORLDBOOK.roles` 只存短称谓，是目录、表现层、AI提示词及RAG自身身份的唯一后端来源；`guidance` 保留完整能力说明。入场选项、对局身份卡与刷新均消费该世界返回的称谓。
- 前端已有离线目录用于接口故障时入场，其公开短名须和世界书一致，不新增另一套规则。世界书正文通过 `_render` 从同一数据生成。

现有入场目录已能切换世界称谓；本次实际复现并修复：海伯利安 `hunter` 在UI为“霸军老兵”、AI/RAG为“军部老兵”；三体将整段能力文字误作角色名。现在采用世界书既有“军部老兵”，三体使用六个短名，完整约束保留在指导中；删除表现层重复称谓表。
