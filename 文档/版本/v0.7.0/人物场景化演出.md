## 2. 实际动作与表情覆盖

- 全身：每世界十二人，每人**一个基础姿态**。人物职业、服装、道具、站坐姿态来自真实插画；待机呼吸和发言倾身是运行时动画，不冒充额外生成的全身动作帧。
- 面部：每世界十二人，每人平静、发言、思考三张真实表情，共 **144 帧**。场景下方特写会按当前公开演出状态切换；“上一位 / 下一位 / 跟随发言”用于查看，减少动效时也保留表情差别。
- 发言：只采纳玩家已能看到的故事中 `is_speech=true` 且 `phase_id` 与当前阶段一致的记录；不会把投票、用药或上一阶段的发言当作当前发言。
- 思考、表决：属于表现层神态，不展示隐藏身份，也不据此推断哪个暗牌角色正在行动。实际模型可见说明与狼队对话仍由既有调试面板按权限呈现。
- 离场：只依据公开 `alive` 状态降低亮度、保留席位和姓名；图集只按公开姓名/席位绑定，不按隐藏阵营取图。

`prefers-reduced-motion: reduce` 下停止人物呼吸和状态倾身动画，环境动画暂停，昼夜与反馈使用静态结果；点击、表情、姓名与合法目标选择照常可用。

## 3. 分帧与素材追溯

生成器输出的排列不保证严格等格。本次全身图先用 image generation 工具忠实重排为 4×3，再只读透明通道计算主要人物轮廓边界。表情先按高置信透明通道的行间谷定位行基线，再取每格主要不透明轮廓边界，纠正上一行肩衣碎条。

运行时以 [`performances.json`](../../../前端/src/worlds/performances.json) 的实际矩形取帧。表情放在严格等于 `rect×scale` 的内层裁切容器内，再在外部方框中居中，非正方形留白不会露出邻格。6×6 只说明表情语义顺序：`(seat-1)*3 + 平静0/发言1/思考2`，不作为裁切坐标。

素材原始 PNG 字节未用 Python 改写。生成来源、实际尺寸、透明通道、SHA-256、单人姿态数量及覆盖范围见[人物演出来源](../../../前端/src/assets/worlds/人物演出来源.json)与[素材清单](../../../前端/src/assets/worlds/素材清单.json)；提示词见[全身重排](素材提示词/人物演出/全身重排.md)及同目录的世界表情、身份修正和潮汐地面提示词。首次过密全身图、旧等格表情预览仅用于排查，不作为当前交付证据。
