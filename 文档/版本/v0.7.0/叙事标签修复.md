# 故事面板叙事标签随世界切换（Issue #68）

创建日期：2026-10-26（北京时间）。状态：**修复完成，待 PR 与合并验收；未打 tag/Release、未部署**。

## 问题与原因

- 复现：选择海伯利安、三体或潮汐档案馆并入局，故事面板仍显示“钟楼记事”；`前端/index.html:159` 写死该文案。
- 根因：`presentation.py` 的主题已定义 `narrator`（钟楼记事 / 营地纪事 / 站内记录 / 馆内潮记），但公开目录与玩家视图没有导出该字段，前端也没有更新入口。
- 影响：仅叙事标签展示，不改变规则、身份、权限或对局数据。

## 修复

- `presentation.py`：`worldbook_catalog()` 与 `present()` 公开各自世界的 `narrator`；不新增秘密字段。
- `前端/index.html`：故事面板眉题改为 `#story-narrator`，默认“钟楼记事”。
- `前端/src/worldart.js`：四世界 fallback 书籍补 `narrator` 并归一化；目录接口失败时仍显示正确标签。
- `前端/src/main.js`：世界选择、入局与 `state` 渲染统一写入 `#story-narrator`；未知世界回退“钟楼记事”，不按身份推断。
