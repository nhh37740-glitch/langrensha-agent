# 群星渡海（v0.7.0，拟定）

本文件登记下一大版本的展示名称、技术版本对应关系与当前状态。当前状态：**三本世界书已合入主线；四世界选择与主题升级由 Issue #63 交付，v0.7.0 尚未发布或验收**。版本未打 tag/Release、未做线上部署，最终大版本验收由监督者组织。

## 命名与版本

- 中文名：**群星渡海**。这是本次按主题完成的工程选择，不写成用户逐字确认。
- 技术版本：**v0.7.0（拟定）**。v0.6.0 已由 Issue #43 的 RAG 交付占用，因此后续大版本按序拟为 v0.7.0；仓库当前没有该 tag 或 Release，包版本也未提升，技术版本号保留作兼容与追溯标识。
- 已发布版本不改名：v0.1.0—v0.5.0 保留原 tag；已有 Release 标题不改。
- v0.6.0 仍是 Issue #43 的 RAG 语义检索交付，不并入本名称；它已合入主线，但尚未打 tag/创建 Release，见 [v0.6.0 版本说明](../v0.6.0/版本说明.md)。

## Web 调试观察（#64）

- 范围：开发阶段 Web 默认开启调试观察，按轮次/阶段/玩家展示 AI 实际返回的显式说明、工具调用摘要与缺失标记，并展示真实狼队内部对话；关闭后隐藏、清空并停止返回审计，恢复正常玩家可见范围。详见[Web 调试观察设计](../../详细设计/开发调试/Web调试观察设计.md)。
- 数据边界：`thinking` 只保存 `AIMessage.content`，不保存隐藏推理、provider 异常或密钥；`/api/state` 与玩家视图不增加调试字段；调试端点仅服务当前 web session，不向 AI 玩家注入秘密。
- 证据：真实 DeepSeek 一局的显式说明与狼队密语、关闭后空审计、契约型 UI 缺失/工具摘要、390px 面板；见[调试观察说明](截图/调试观察说明.md)。后端 274 项 pytest（本地排除 4 项缺 numpy 的语义用例）与前端 11 项 Playwright 通过。
- 状态：本 PR 交付；v0.7.0 仍未打 tag/Release、未部署。本单不改变 #63 的四世界主题和版本图绑定。
