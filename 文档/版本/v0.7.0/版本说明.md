# 群星渡海（v0.7.0，拟定）

本文件只登记下一大版本的展示名称与技术版本对应关系，不表示该版本已启动、已交付或已发布，也不改变 #39—#41 的排队状态、验收前置条件与“尚未实施”事实。

## 命名与版本

- 中文名：**群星渡海**。这是本次按主题完成的工程选择，不写成用户逐字确认。
- 技术版本：**v0.7.0（拟定）**。v0.6.0 已由 Issue #43 的 RAG 交付占用，因此后续大版本按序拟为 v0.7.0；仓库当前没有该 tag 或 Release，包版本也未提升，技术版本号保留作兼容与追溯标识。
- 已发布版本不改名：v0.1.0—v0.5.0 保留原 tag 与 Release 标题。
- v0.6.0 仍是 Issue #43 的 RAG 语义检索交付，不并入本名称；它已合入主线，但尚未打 tag/创建 Release，见 [v0.6.0 版本说明](../v0.6.0/版本说明.md)。

## 规划范围与状态

拟覆盖三个排队中的世界书任务：

- #39 海伯利安世界书
- #40 三体世界书
- #41 原创“潮汐档案馆”世界书

三者当前均未实施，仍按原顺序等待当前版本事项验收通过后串行进入；本命名不提前启动调研、内容编写、接入或发布。命名理由：三个世界分别指向星际朝圣、宇宙文明与海洋记忆，“群星渡海”以星与海连接三者，简洁、可记忆，避免空泛营销词。
