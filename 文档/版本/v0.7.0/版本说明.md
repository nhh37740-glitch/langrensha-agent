- 已发布版本不改名：v0.1.0—v0.5.0 保留原 tag；已有 Release 标题不改。
- v0.6.0 仍是 Issue #43 的 RAG 语义检索交付，不并入本名称；它已合入主线，但尚未打 tag/创建 Release，见 [v0.6.0 版本说明](../v0.6.0/版本说明.md)。

## 世界书选择与主题（#63）

- 范围：四本世界书的公开目录、入镇选择、建局持久化、玩家视图/AI/RAG 一致性与四套主题视觉；详见[世界书选择与主题设计](../../详细设计/世界书/世界书选择与主题设计.md)。
- 交付：`GET /api/worldbooks` 只返回公开字段；`POST /api/game` 持久化 `state.worldbook`；刷新后主题/文案/身份保持一致；秘密条目和隐藏身份不进入目录、图片或非本人视图。
- 美术：Anthropic frontend-design Skill、Phaser 纹理/tween、Kenney UI/天空（CC0）、ChatGPT 生成的潮汐低潮背景与透明底 9 号公开席位「墨篱」画像；来源、提示词、哈希与许可见 `前端/src/assets/kenney/来源.md`、`前端/src/assets/ai/来源.md` 和 `.agents/skills/frontend-design/`。
- 证据：真实浏览器桌面/390px 截图与选择→建局→刷新→检索的 Playwright 用例；改造前基线截图同目录。5 项必需 CI 与 Codex 审查在 PR 中记录。
- 状态：本 PR 交付；v0.7.0 仍未打 tag/Release、未部署。
