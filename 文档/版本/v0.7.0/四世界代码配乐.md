# 四世界代码配乐

对应 [Issue #76](https://github.com/nhh37740-glitch/langrensha-agent/issues/76)。2026-10-26 用户改为由 Codex 用代码创作既定曲目，不再使用 Gemini API 或网页生成。配乐是本次原创编排，不使用影视、游戏或小说改编作品的现成旋律。

## 交付范围

- 公共菜单 1 首、每世界 10 首，共 **41 首背景音乐**；另有四世界各 3 条转场，共 **53 段**。
- 29 首可循环：公共菜单与每世界的主题、白昼、对质、夜晚、投票、遗言、阅读；12 首独立结局；12 条一次性过门。
- [音频与试听页](../../../素材/音乐/试听.html)、[曲目目录](../../../素材/音乐/曲目目录.md)、[技术核验](../../../素材/音乐/技术核验.json)、[乐谱核验](../../../素材/音乐/乐谱核验.json)。GitHub 不直接运行 HTML；本地打开目录，或用下方静态服务试听。
- [创作脚本](../../../制作/配乐/生成配乐.py)、[结构化清单](../../../制作/配乐/曲目清单.json)、[逐曲 JSON / MIDI 乐谱](../../../制作/配乐/乐谱)。无需音乐生成服务、账号、API key 或网络模型。

**本单交付音乐素材与制作工具，尚未接入游戏自动播放。** 声音风格的最终选择仍需实际试听；响度和接缝的技术检查不能代替听感判断。不新增播放器系统，也不改变游戏业务或既有架构图绑定。

## 创作与编排

| 世界 | 调式与四音动机 | 主要音色 |
| --- | --- | --- |
| 雾钟镇 | D 小调；D—F—E—A | 柔钢琴、单簧管、大提琴、拨弦、远铜钟 |
| 海伯利安 | E 弗里几亚；E—F—B—A | 处理电钢琴、低弦、竖琴、金属泛音 |
| 三体 | C 利底亚；C—D—F♯—G | 干净钢琴、薄长音、圆润正弦脉冲、信号泛音 |
| 潮汐档案馆 | A 多利亚；A—C—D—E | 马林巴、尼龙拨弦、单簧管低音区、铜片琴 |

循环曲用十六小节组织主题与应答，和声每两小节变化；后半段调整转位、音区和节奏。白昼是较疏的分解音，对质与投票提高问答和脉冲密度，夜晚减少旋律与敲击，遗言降低动态，阅读留出更多空拍。不是将同一音轨改名或只改速度。结局用六至八小节及余韵收束；光明结局可借用大调主和弦，暗影结局转暗，未定结局保留开放音程。

使用边界沿用原清单：夜曲统一覆盖公开的夜间阶段，不根据未公开身份切曲；遗言与落票过门保持中性。胜负结局只能在结果公开后播放。技能音效属于另一套资产，不能用长背景音乐替代。

## 合成与核验

以本地 FluidR3 GM 音色库离线合成，音符独立采样后按乐谱混合；循环释放尾音与房间反射环绕叠加，避免生硬截断。三体另用代码合成轻低频脉冲，结局与过门在末尾停止脉冲并保留余韵。无歌词、语音或录音人声。

输出为 48 kHz 双声道 Ogg/Vorbis。背景与转场目标为 -24 LUFS，结局为 -22 LUFS；保留至少约 3 dB 真峰值空间。逐曲检查最终压缩音频的解码长度、非静音、有效采样、响度、真峰值、循环边界导数、结局衰减与过门时长，并记录 SHA-256。循环曲不以首尾强行归零伪造接缝通过；播放端仍需使用合适的无缝循环方式。

独立乐谱检查核对 53 个不同编号、29 首循环曲、实际音符范围、循环曲调内音、编排差异、MIDI 的 NoteOn/NoteOff 配对、节拍及与 JSON 乐谱的一致性。所有检测结果见交付回执，不能把未通过的条目记作完成。

## 重建与试听

制作环境需要 Python 3.12、numpy、FFmpeg、libfluidsynth 与 FluidR3 GM；不增加游戏运行依赖。Debian/Ubuntu 的系统包为 `libfluidsynth3`、`fluid-soundfont-gm`、`ffmpeg`。音色库不随仓库复制，使用本机安装的文件。

```bash
python 制作/配乐/生成配乐.py --soundfont /usr/share/sounds/sf2/FluidR3_GM.sf2
python 制作/配乐/核验乐谱.py
python -m http.server 18176 --bind 127.0.0.1 --directory 素材/音乐
```

访问 `http://127.0.0.1:18176/试听.html`。可用 `--only mist_theme threebody_night` 重建指定曲目，`--out` 指定音频输出目录。JSON 乐谱是实际合成依据，MIDI 供继续编辑；MIDI 播放器自带音色和混响可能与本次成品不同。编曲可重复，音频字节仍受音色库及合成/编码版本影响，不能保证跨环境逐字节相同。

FluidR3 GM 音色来自 Frank Wen 等，采用 MIT 许可，见[完整来源与许可](../../../素材/音乐/来源.md)和[保留的上游声明](../../../素材/音乐/FluidR3许可证.txt)。原曲目清单与历史提示词保留在 Issue #76，Gemini 自动化取消记录继续有效。
