# v0.3.0 完整雾钟镇对局

对应 #12，完成 #1、#3、#4、#5、#6 的首版实施范围。完整十二人规则、全部角色能力、独立人格与身份指导、LangGraph 原生工具行动及检索、按权限召回、可追溯的真人摘要与可编辑建议，连接 Phaser 场景/人物/能力动画及 HTML 对局界面。FastAPI 会话隔离与 SQLite 保持同局恢复，发行包自带静态资源，并提供非 root 容器及部署说明。

[实际验收记录](../../验收/完整可玩版验收.md)区分离线策略、真实模型、浏览器、构建与用户服务器上线。规则的工程选择及并发/死亡信息边界见[实施规格](../../详细设计/首个可玩版本/完整可玩版实施规格.md)。本版只提供雾钟镇一个世界；跨世界视觉切换待第二份世界内容，用户服务器未指定则不宣称线上交付。

[完整对局架构图](完整对局架构.html)与[可编辑图源](完整对局架构.architecture.json)引用已提交源码。使用独立 evidence 分支永久保留原始图源提交，避免 squash 合并后失去证据；CI 从对应归档 ref 获取并核对 SHA，重新生成图且执行实际浏览器检查。发布后归档分支不移动。
