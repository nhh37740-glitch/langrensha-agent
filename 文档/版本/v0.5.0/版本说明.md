# v0.5.0 雾钟镇视觉与动效重做

对应 #21。重做 WebUI 视觉语言与 Phaser 场景表现，让入镇、对局、雾夜、白昼、行动可用、私密记录、断线提示与结局都有统一、可观察的视觉状态；只改前端表现层与测试，不改变后端规则、角色技能、检索权限、公开 API 或部署方式。

- 新增设计 token（底色、文字、铜金强调、私密、错误、间距、圆角、动效时长与缓动），统一按钮、卡片、输入、名单与记录状态；桌面与 390px 手机端保持可读、可操作。
- `前端/src/scene.js` 由简单几何色块升级为程序化分层绘制：昼夜天空、星空与月光、两层山影、带石缝/拱门/钟室/铜铃的钟楼、广场石纹与中央铃纹、十二名带斗篷/兜帽变体的旅人、当前玩家光环、执铃人铜铃、离场灰化、雾层/灯火/萤火。
- 技能反馈覆盖观星、药剂、开枪、誓印与自曝，均有触发条件、时长与减少动效替代；`prefers-reduced-motion` 下连续动画停止、状态切换即时完成，功能不受影响。
- Playwright 保留原有入镇、私密、权限、札记、刷新、手机、完整对局、暗牌与断线用例，新增减少动效模式用例，并补充 `data-mode`、`data-phase`、`data-turn`、`data-error`、`data-motion` 状态断言。
- 截图证据由 GitHub Actions 的真实 Chromium 生成并归档在[截图](截图/)，桌面端覆盖入镇、行动可用、私密记录、断线提示与结局，手机端覆盖 390px 对局；详细 token、状态表、动效表与工具取舍见[视觉与动效说明](视觉与动效说明.md)。

版本号同步提升到 0.5.0（`pyproject.toml` 与 `前端/package.json`/锁文件），本 PR 不提前创建 tag；合并并通过五项主线检查后按规范打 v0.5.0。用户服务器部署与线上验收仍由 #14 跟踪，本次不部署服务器。
