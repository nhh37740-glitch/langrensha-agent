# v0.5.0 视觉与动效说明

对应 #21；决定日期：2026-10-24（北京时间）。范围仅限前端表现层与既有测试，不改变后端规则、角色技能、检索权限、公开 API 或部署方式。文中“已实现”均指本版本代码。

## 视觉方向

以“雾、钟楼、秘密、证词”为叙事核心：低饱和墨绿雾夜、旧纸与铜金点缀、衬线标题与克制留白。界面层级从外到内为：环境（雾层、暗角、颗粒）→ 场景（钟楼、广场、旅人）→ 信息（身份、名单、记录）→ 行动（本轮抉择）。不使用通用 SaaS 仪表盘风格的亮色卡片与高饱和渐变。

## 状态与可观察表现

状态由 `前端/src/main.js` 写入 `<html>` 的 `data-*` 属性，CSS 与 Phaser 共同消费；不使用隐藏身份或私聊内容作为视觉输入。

| 状态 | 触发 | 可观察表现 | 实现位置 |
| --- | --- | --- | --- |
| 入镇 | 无对局或重开 | 入镇卡、雾夜场景、无回合徽标 | `data-mode="entering"`；`.intro` |
| 对局·雾夜 | `state.night` 为真 | 月光、星空、灯火、雾层与夜景配色 | `data-phase="night"`；`scene.js` `drawWorld` |
| 对局·白昼 | 天亮后 | 天色转暖、灯火减弱、白昼配色 | `data-phase="day"`；`scene.js` `applyNight` |
| 行动可用 | 本玩家存在合法行动 | 铜金回合徽标、行动区顶光、提交按钮高亮 | `data-turn="you"`；`.turn-badge`、`.action-area` |
| 等待旅人 | 无合法行动且自动推进 | 思索指示点与状态文案 | `data-turn="waiting"`；`.waiting` |
| 私密记录 | 当前玩家专属事件 | 左侧实质感标记与“仅你可见” | `.entry.private`；`presentation` 已过滤数据 |
| 断线/失败 | 请求失败（非 HTTP 拒绝） | 错误条、连接中断说明、按钮恢复可用 | `data-error="network"`；`.error.is-network` |
| 结局 | `state.winner` 有值 | 结局卡与暖金呼吸光、场景暗角变化 | `data-mode="ended"`；`.ending` |
| 减少动效 | 系统 `prefers-reduced-motion` 或运行期开关 | 连续漂浮/闪烁停止，状态切换即时完成 | `data-motion="reduced"`；CSS 媒体查询与 `scene.js` `setReducedMotion` |

## 动效清单

| 动效 | 触发 | 时长/缓动 | 减少动效时 |
| --- | --- | --- | --- |
| 雾层漂移 | 页面常驻 | 38–62s，交替往复 | 停止，保留静态雾层 |
| 灯火/萤火呼吸 | 场景常驻 | 1.6–4.8s | 停止 |
| 昼夜过渡 | `state.night` 改变 | 620ms `Sine.easeOut` 遮罩淡出 | 直接切换 |
| 技能反馈 | 新 `effect` 事件（观星/药剂/开枪/誓印/自爆） | 900–1100ms 扩散与粒子 | 仅保留 240ms 静态印记 |
| 记录进入 | 新故事条目 | 260ms 上浮淡入 | 直接出现 |
| 回合徽标脉冲 | `data-turn="you"` | 2.6s 呼吸 | 静态显示 |
| 提交按钮微光 | 常驻 | 6.5s 扫光 | 取消 |
| 错误提示 | 请求失败 | 260ms 轻微位移 | 直接显示 |

所有动效只做视觉反馈，不阻塞操作或自动推进；`prefers-reduced-motion: reduce` 下动画时长被压缩到接近 0，Phaser 连续 tween 暂停，Playwright 减少动效用例验证仍可入镇、行动与恢复。

## 工具候选与取舍

实施前比较了 Issue 列出的候选。结论：**不新增第三方 UI/动画依赖**，使用仓库已有的 Phaser Graphics/Tween、CSS 变量与媒体查询、原生 Web Audio；不引入 Figma/Rive/GSAP/Lottie/Spline 的运行时或资产链路。依据：

| 候选 | 用途 | 结论与原因 |
| --- | --- | --- |
| Figma | 视觉方向与交付稿 | 未采用为运行时依赖；本仓库无设计文件托管与评审流程，纳入会要求外部账号与可导出资产，无法在离线构建中校验 |
| Rive | 角色/图标交互动画 | 未采用；需要 `.riv` 运行时包与资产生产管线，增加体积与许可证核对成本，当前程序化 Graphics 已能覆盖 12 名旅人与 5 类技能反馈 |
| GSAP | DOM/Phaser 时间线 | 未采用；与 Phaser Tween 职责重叠，额外运行时体积无对应收益；许可证与版本锁定需单独核对 |
| Lottie/dotLottie | 图标/装饰动画 | 未采用；需要外部 JSON 资产与播放器，违反“资产可追溯、可在仓库或允许依赖中稳定复现”的约束 |
| Spline | 3D 场景 | 未采用；体积、渲染成本与离线构建不可控，明显超出当前 2D 视觉范围 |

小范围验证方式：对照现有依赖锁定（`requirements-dev.lock`、`前端/package-lock.json`）与构建体积上限（Vite `chunkSizeWarningLimit: 1800`），确认 Phaser Tween + CSS 动画 + 程序化 Graphics 可覆盖全部状态反馈；新增运行时依赖会使离线构建、许可证清单与截图基线同时变化，因此不采用。若后续需要 Rive/GSAP 等能力，先建单独 Issue 做原型、体积与许可证验证，再决定依赖。

## 场景重建

`前端/src/scene.js` 由 12 个色块圆环升级为程序化分层绘制：

- 天空：昼夜渐变、54 颗星、月相与光晕、两层远近山影。
- 钟楼：石缝、拱门、台阶、钟室、铜铃、屋顶与风向标；夜间窗光与铃光。
- 广场：椭圆地面、环形石纹、24 道放射石缝、中央铜铃纹样。
- 旅人：每人独立的斗篷、兜帽/发型变体、领口与铜扣、座位号；当前玩家有光环标记，执铃人有铜铃标记，离场者灰化；颜色取服务器返回的公开人物色，不根据未公开身份着色。
- 环境：雾层、灯火、萤火、暗角与颗粒均为程序化图形，无外部图片或字体依赖。
