# 海伯利安世界书调研

调研日期：2026-10-25（北京时间）。对应 Issue：#39。状态：调研完成，代码与测试见本 PR。

## 1. 结论摘要

- 原作是丹·西蒙斯 1989 年出版的长篇小说《Hyperion》，1990 年获雨果奖最佳长篇与轨迹奖最佳科幻长篇；首版由 Doubleday Foundation 出版，Bantam Spectra 于 1990 年发行平装本。
- 故事发生在约二十八世纪的霸主（Hegemony）宇宙：万星网、远距传输门、智核、驱逐者与边境行星海伯利安共同构成背景；核心舞台是海伯利安上的光阴冢与伯劳。
- 本世界书只使用公开书目、百科与研究条目可核验的**设定层事实**，不复制小说原文，不做逐章替代性复述，也不声称读完或取得未授权全文。
- 狼人杀适配是**本项目原创改编**：十二人编制、荆棘使徒秘密小组、时隙观测、药箱、侧枪与朝圣誓约等身份能力，均以雾钟镇既有规则为骨架，不增加规则权限。

## 2. 授权与取材边界

- 没有 clone、下载或转存任何未授权小说全文、MOBI/EPUB/PDF；没有使用第三方书籍仓库的代码许可证推断原小说授权。
- 没有把原著全文放入 RAG、测试数据或 Git。本模块中的文字均为自行撰写的摘要，个别专名（如 Hyperion、Shrike、TechnoCore）属于必要指称。
- 中文译名参考中文版公开书目、出版新闻与常见译法并在项目内统一，不表示与任一纸书版本逐字一致；不同版本译名可能不同。没有使用中文版正文。
- 本轮无法核验或原著本身未定的事项，在下文标为“未知”，不用印象补成 canon。

## 4. 可核验的原著事实

### 4.1 出版与奖项

- 作者：丹·西蒙斯（Dan Simmons，1948 年生）。
- 英文首版：1989 年 6 月，Doubleday Foundation；1990 年 3 月 Bantam Spectra 平装本。
- 1990 年雨果奖最佳长篇、1990 年轨迹奖最佳科幻长篇；续作为 1990 年《The Fall of Hyperion》。
- 中文版：2007 年万卷出版公司出版前两卷；2012 年江苏文艺出版社以《当人类决战机器人：海伯利安》分上下册出版；2014 年 11 月吉林出版集团有限责任公司（读客文化）出版四部曲新版，ISBN 978-7-5534-5293-7。

| --- | --- | --- |

### 4.3 明确标为“未知”的内容

- 伯劳的真正起源、最终目的与幕后力量：首作刻意保留为谜，本项目不写成确定事实。
- 海伯利安各城市、营地与局部地貌的精确名称和方位：本轮只核验到行星级与光阴冢级信息，不凭印象补写。
- 朝圣者之外普通居民的具体制度、语言与日常生活：公开资料不足，本项目营地规则标为原创。
- 原著人物的最终命运与续作揭示：本世界书不使用，避免把后续作品的揭秘混入首作舞台。

## 5. 本项目改编

### 5.1 十二人编制与角色映射

原著朝圣队为七人；狼人杀标准局需要十二个座位，因此本局把“最后一批朝圣者”改写为十二名在场者，并明确这是改编。角色映射如下：

| 狼人杀角色 | 本项目称谓 | 世界内解释 | 机制来源 |
| --- | --- | --- | --- |
| 狼人 | 荆棘使徒 | 混在朝圣队中的秘密小组，夜间献祭 | 原创改编 |
| 平民 | 朝圣者 | 无夜间能力的在场者 | 沿用标准局 |
| 预言家 | 时隙观测者 | 读取时隙残影，判断阵营 | 原创改编 |
| 女巫 | 随队医官 | 修复剂与神经毒素各一瓶 | 原创改编，机制沿用标准局 |
| 猎人 | 霸军老兵 | 离场时最后开枪 | 原创改编，机制沿用标准局 |
| 白痴 | 立誓者 | 首次被逐离亮出朝圣誓约留下，失去选票 | 原创改编，机制沿用标准局 |

### 5.2 世界规则

- 白天在朝圣营地公开议事，可推选执灯人；执灯人最后陈述，表决一票抵一票半，离场时可移交或毁去灯盏。
- 夜间荆棘使徒各投一票，唯一最高票才成为献祭对象；同票或无人选择则平安。
- 朝圣者要让荆棘使徒全部离开；荆棘使徒要让普通朝圣者全部消失，或让四种守望身份全部消失。
- 离场者仍能旁听公开交谈；清晨只公布谁离场，不公布死因。
- 以上胜负与流程与雾钟镇标准局一致，只替换叙事外衣；世界书条目不能增加工具、目标或夜间权限。

### 5.3 秘密权限

| 条目 | 可见角色 | 内容性质 |
| --- | --- | --- |
| `world:hyperion:thorn-pact`、`world:hyperion:thorn-rite` | 仅 wolf | 原创秘密小组与夜间规则 |
| `world:hyperion:seer-eye` | 仅 seer | 原创时隙观测说明 |
| `world:hyperion:medkit` | 仅 witch | 原创药箱说明 |
| `world:hyperion:sidearm` | 仅 hunter | 原创侧枪说明 |
| `world:hyperion:oath` | 仅 idiot | 原创朝圣誓约说明 |
| 其余条目 | public | 公开设定与营地规则 |

秘密条目只作身份提示和氛围补充；真正的权限仍由规则内核与玩家视图决定。检索层先按查看者角色过滤，再建立索引，因此秘密文本不会进入其他角色的候选集。

## 6. 狼人杀适配说明

- **信息不对称**：公开条目对应所有玩家可见的世界常识；秘密条目对应身份私有知识。两者分开，避免把“世界设定”误当成“已公开证词”。
- **不增加权限**：世界书是知识层，不是规则层。身份能力、目标、票权、夜间窗口仍由 `full_game` 与 `rules` 决定。
- **可检索**：`ask_world` 只取当前世界书且只取查看者可见条目；`self_info` 使用当前世界的角色称谓与身份指导。
- **可审计**：条目保留稳定 id 与标题，检索结果带来源，便于核对“这句话来自哪条世界设定”。
- **可扩展**：新增世界只需在 `src/langrensha/worldbooks/` 放一个暴露 `WORLDBOOK` 的模块，不改注册文件。

## 7. 接入设计

### 7.1 最小接口

每个世界模块暴露 `WORLDBOOK` 字典：

```python
{
    "id": "hyperion",
    "name": "海伯利安",
    "basis": "来源与改编说明",
    "entries": [
        {"id": "world:hyperion:arrival", "title": "...", "text": "...", "visibility": "public"}
    ],
    "roles": {"wolf": "荆棘使徒", ...},
    "guidance": {"wolf": "...", ...},
    "personas": [("名字", "描述", "#rrggbb")],
}
```

- `roles`：角色称谓映射；`guidance`：身份指导映射；两者缺失键时回退雾钟镇，避免提示词缺字段。
- `visibility`：`"public"` 或角色列表；角色列表表示仅这些角色可见。
- 条目 id 命名空间：`world:<book id>:<slug>`；雾钟镇为兼容既有来源保留历史 `world:arrival` 等 id，是唯一豁免，代码中有注释。
- `personas`：十二个人物条目，供后续表现层选用；本轮不切换到海伯利安视觉。

### 7.2 自动发现与校验

- `pkgutil.iter_modules` 扫描同包模块，导入后读取 `WORLDBOOK`；新增模块无需改 `__init__.py`。
- 注册时校验必填字段、条目 id 前缀/唯一性、可见角色范围、角色与指导映射；错误在导入期暴露，避免坏数据进入对局。
- `get_worldbook(id)` 对未知 id 抛 `KeyError`；检索层转换为 `Rejected("unknown_worldbook")`，不静默切到其他世界。
- 默认世界仍为 `mist`；未携带 `worldbook` 的旧视图与现有对局行为不变。

### 7.3 检索与提示词接入

- `retrieval.build_chunks` 的世界名取自当前世界书，不再写死“雾钟镇”。
- `retrieval.ask_world` 只读取当前世界书，先调用 `visible_entries(book, role)` 过滤，再交给语义/词项检索；身份指导仍以 `self:guide` 来源返回。
- `retrieval.self_info` 使用当前世界的角色称谓与身份指导。
- `ai.system_prompt` 使用当前世界的名称、角色称谓、身份指导与首条公开入场背景；mist 默认提示与既有测试一致。
- 入口为玩家视图的可选键 `view["worldbook"]`，本轮不新增建局选择参数；完整剧本视觉切换留后续。因此本轮交付的是**检索知识层接入**，不是可玩的完整海伯利安剧本。
