## 1. 授权、取材边界与表述约定

### 1.1 没有使用未授权全文

用户提供的两个 GitHub 书籍仓库只是线索。其小说全文/电子书的授权状态未核实，因此本 Issue：

- 不 clone、不批量下载、不转存其中的 MOBI/EPUB/PDF/全文；
- 不另找未授权镜像，不把仓库代码许可证当成原小说授权；
- 不把原著全文放入 RAG，不做全书逐章替代性复述；
- 不宣称已经读完原著全文。

本调研只使用**作者/出版社公开书目、授权可公开访问的节选、可靠媒体/研究评论、百科条目**等可合法取得的材料，自行归纳、自行表述；必要的短语引用在文中注明来源。世界书条目为原创改写，单条正文不超过 300 字，总正文约 2200 字，规模上也不构成全文替代。

### 1.2 权利状态

《三体》小说著作权归刘慈欣及相应出版方。本世界书是**非官方改编**，未获得刘慈欣、重庆出版社、Tor Books 或任何影视方的改编授权；当前仅作为本项目非商业学习/原型内容使用，不声明商用或公开发行授权。若权利方提出要求，应移除或替换相应内容。`WORLDBOOK["basis"]` 已把这一点写入数据。

### 1.3 三级区分

| 层级 | 本调研中的含义 | 使用方式 |
| --- | --- | --- |
| 小说 canon | 刘慈欣《三体》三部曲正文中的设定、人物、事件 | 只取公开资料能相互印证的骨架；不凭印象补细节 |
| 影视改编 | 腾讯 2023 电视剧、Netflix 2024 剧集等 | 只用于说明“改编会改什么”，**不作为小说 canon**，不进入世界书 |
| 本项目原创改编 | 临海监听站困局、身份名、夜间行动的叙事包装、12 个原创船员人格 | 在世界书和文档中明确标“原创改编”，不伪装成原著 |

无法从公开材料确认的内容，本文标“未知”，不硬写。小说设定与真实天体物理的差异也单独说明，避免把虚构前提当成科学结论。

## 3. 小说 canon、影视改编与本项目改编的分界

| 维度 | 小说 canon | 腾讯 2023 剧版 | Netflix 2024 剧版 | 本项目世界书 |
| --- | --- | --- | --- | --- |
| 时代与地点 | 中国、红岸基地、北京、联合国/PDC、太阳系与深空 | 基本沿用小说第一部的中国背景 | 故事移植到英国，以伦敦和“牛津五人组”为中心 | 小说层面的世界背景 + 原创“临海监听站”困局 |
| 主要人物 | 叶文洁、汪淼、史强、罗辑、章北海、程心、云天明等 | 保留汪淼、史强、叶文洁、常伟思、丁仪等 | 改变若干中国角色的性别、族裔、姓名，新增/重组人物 | 原著人物只作背景条目；玩家使用 12 个原创船员人格 |
| 情节范围 | 三部曲，从第一次接触到宇宙结局 | 主要改编第一部，30 集，补充配角与情感细节 | 8 集，压缩三部曲，重排人物关系 | 只取世界规则与概念，不搬任何一部的情节线 |
| 影像/命名 | 小说文字设定 | 中国电视剧的视觉与台词处理 | 英文语境下的 “San-Ti” 等命名与视觉 | 中文小说术语（三体人、智子、面壁者、执剑人） |
| 对世界书的作用 | **唯一 canon 来源** | 只用于说明改编差异 | 只用于说明改编差异 | 明确标注“原创改编”，不冒充 canon |

### 3.1 影视改编不能倒灌小说 canon

- 腾讯版总体“忠实原著”，但 S4 明确指出它放大了沙瑞山、慕星、徐冰冰等配角，并增加原创情感戏；这些是电视剧的改编，不是小说正文。
- Netflix 版把故事移植到英国，改变若干中国角色的性别、族裔与姓名（S5），并采用“牛津五人组”等剧集结构（S11）；这些都不是小说 canon。
- 因此世界书不采用“牛津五人组”、Netflix 的 “San-Ti” 命名、腾讯版原创配角的经历，也不把任何影视剧的视觉设定写成小说事实。

### 3.2 本项目原创改编

以下内容在原著中没有对应情节，属于为本项目狼人杀对局设计的原创框架，文档和代码中均标“原创改编”：

- “临海监听站”困局：十二名观测员被风暴困住，白天交换证词、夜里有人被清除；
- 六个游戏身份的世界观名称：潜伏者、地球公民、监听员、面壁者、执剑人、冬眠者；
- 夜间行动的叙事包装：智子锁定、信号归属推演、两套预案、坐标广播、冬眠舱；
- 12 个原创船员人格（老监听员、舰载工程师等），不是叶文洁、汪淼等原著人物。

| 伊文斯 | ETO 的建立者之一，降临派核心 | `eto`、`judgment_day` 的背景 |
| 申玉菲 | 与 ETO 有关的科学家 | 只作背景，具体派别细节不展开 |

原著人物只作为**世界背景与检索资料**，不直接作为玩家身份或人格；玩家使用 12 个原创船员人格，避免把 canon 人物的命运和关系强加给对局。

### 4.5 秘密权限

`visibility` 只有两种取值：`"public"`，或角色列表（如 `["wolf"]`）。检索层必须先按查看者角色过滤，再做索引/排序；秘密条目的标题和正文都不得进入其他角色的候选集、答案或来源列表。

| 条目 id | 内容 | visibility | 理由 |
| --- | --- | --- | --- |
| `world:threebody:wolf_advent` | 潜伏者身份、夜袭规则、白天伪装 | `["wolf"]` | 狼队内部信息 |
| `world:threebody:wolf_sophon` | 智子遮蔽行动痕迹、选择夜间目标 | `["wolf"]` | 狼队策略 |
| `world:threebody:wolf_wallbreaker` | 破壁人如何识别掌握信息的人 | `["wolf"]` | 狼队策略 |
| `world:threebody:seer_darkforest` | 黑暗森林推演 + 查验规则 | `["seer"]` | 观星者专属推理与技能提示 |
| `world:threebody:seer_redcoast` | 红岸旧档：内应可能是主动选择 | `["seer"]` | 观星者专属背景 |
| `world:threebody:witch_plan` | 面壁者两套预案（解药/毒药） | `["witch"]` | 药师专属技能信息 |
| `world:threebody:witch_timing` | 用药时机与公开解释策略 | `["witch"]` | 药师专属策略 |
| `world:threebody:hunter_broadcast` | 执剑人坐标广播（猎人开枪） | `["hunter"]` | 猎人专属技能信息 |
| `world:threebody:idiot_hibernation` | 冬眠舱（白痴首次免逐离） | `["idiot"]` | 白痴专属技能信息 |

其余 24 条为 `"public"`，覆盖世界规则、地点、阵营、人物与历史事件。公共条目本身不包含任何角色专属技能提示；角色的技能说明只放在 `roles`/`guidance` 和对应秘密条目中。

## 5. 如何适配狼人杀

### 5.1 身份映射

| 标准角色 | 三体世界书名 | 叙事包装 | 规则是否改变 |
| --- | --- | --- | --- |
| 狼人（wolf） | 潜伏者 | 替三体文明清除地球防线的内应；夜里用智子锁定目标 | 否 |
| 平民（villager） | 地球公民 | 没有夜间能力的观测员/船员 | 否 |
| 预言家（seer） | 监听员 | 每夜推演一人的“信号归属”，只得到阵营 | 否 |
| 女巫（witch） | 面壁者 | 两套秘密预案：解药（掩护）与毒药（清除） | 否 |
| 猎人（hunter） | 执剑人 | 离场时广播坐标，带走一人 | 否 |
| 白痴（idiot） | 冬眠者 | 第一次被逐离启动冬眠舱留下，失去选票 | 否 |

### 5.2 夜间行动与规则的对应

| 现有规则 | 世界书叙事 | 不得改变的点 |
| --- | --- | --- |
| 狼队夜间私语、各投一票，唯一最高票生效，平票无袭击 | 潜伏者通过智子协调“锁定”目标 | 仍是唯一最高票；平票/无人选择仍无袭击 |
| 预言家每夜查验一人阵营，不可查自己/连续两夜同一人 | 监听员核对“信号归属” | 只给阵营，不给具体职业；限制不变 |
| 女巫一瓶解药一瓶毒药，每夜最多一瓶，不可自救 | 面壁者的两套预案 | 解药只救当夜袭击对象；毒药可指定；次数不变 |
| 猎人被袭击/逐离时可开枪，毒杀不能开枪 | 执剑人广播坐标 | 胜负已定不开枪；毒药封锁；仍只带走一人 |
| 白痴首次被逐离亮牌留下，失去选票，夜间不能免死 | 冬眠者启动备用舱 | 只免第一次逐离；夜间死亡无效；仍可发言 |

### 5.3 检索与信息隔离

1. **先过滤，再索引**：对每个查看者，只把 `public` 条目、其角色对应的秘密条目、其自己的 `guidance` 放入候选集；不得先对全量条目建索引再过滤结果。
2. **来源列表同样过滤**：答案中引用的 `sources` 只能来自已过滤集合；不能出现“答案没写、来源里却带出秘密条目”的泄漏。
3. **跨世界隔离**：所有条目 id 以 `world:threebody:` 开头，世界 id 为 `threebody`；检索按世界范围限定，不能把三体条目混入雾钟镇，也不能反向混入。
4. **角色指导只取本人**：`guidance` 是六个角色的映射，接入层只能把 `guidance[viewer_role]` 加入文档，不能把整个字典拼进上下文。
5. **不靠提示词保密**：秘密条目的隔离由数据结构和过滤逻辑保证，不能只靠“请勿泄露”的提示词。

### 5.4 为什么不做过度设计

- 不新增规则模块、不新工具、不改 `rules.py`/`full_game.py`；世界书是只读资料，不授予额外权限。
- 不引入第三阵营、不增加胜利条件；ETO 只作为狼队背景。
- 不做独立的向量库或新依赖；复用现有 `retrieval.py`/`semantic.py` 的接入由队员 A 的共享 PR 完成。
- 不把影视剧的视觉资产、角色关系或原创情节写进世界书；视觉/动画留到后续版本。

### 6.1 模块

```python
{
    "id": "threebody",
    "name": "三体",
    "basis": "来源/授权说明",
    "entries": [{"id": ..., "title": ..., "text": ..., "visibility": ...}],
    "roles": {"wolf": ..., ...},
    "guidance": {"wolf": ..., ...},
    "personas": [(名字, 描述, "#rrggbb"), ...],

```

- 33 条条目：24 条 public + 9 条角色秘密；
- 6 个角色键与现有身份一致：wolf/villager/seer/witch/hunter/idiot；
- 12 个原创船员人格，颜色为 6 位十六进制；
- 条目正文均不超过 300 字，适合现有分块检索。

### 6.3 测试

`tests/test_worldbook_threebody.py` 直接 `from langrensha.worldbooks.threebody import WORLDBOOK`，覆盖：

- 数据契约：顶层键、id/name/basis、6 个 roles/guidance、12 个 personas；
- 条目 id 唯一、全部 `world:threebody:` 前缀、单条 ≤300 字、总正文 <12000 字；
- visibility 只能是 `"public"` 或已知角色的非空列表；
