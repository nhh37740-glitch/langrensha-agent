Wolfcha 的 README 尾部写 MIT，但实际 [LICENSE](https://github.com/oil-oil/wolfcha/blob/main/LICENSE) 为 Apache-2.0，GitHub API 的识别结果也为 Apache-2.0。正式复用时应按选定提交再次核对 LICENSE、版权声明及素材来源，不能直接依据 README 的 MIT 文案。
