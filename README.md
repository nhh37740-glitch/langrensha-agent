# 雾钟镇：狼人杀智能体

一名真人与十一名 DeepSeek AI，在 Phaser 呈现的钟楼广场完成十二人预女猎白文字对局。Python 后端裁定全部技能、警长竞选、平票、死亡触发及胜负；LangGraph 限制原生工具行动循环。真人可以指定或随机取得身份。

## 先看懂后端

后端的主线是：**Web 确定操作者 → 服务层管理事务 → 规则层裁定 → SQLite 保存**。AI 提出选择，最终仍经过同一套规则。

从[后端源码阅读指南](文档/架构/后端源码导读/阅读指南.md)开始：先读三个核心角色，再跟一次投票进入源码。配套[结构图](文档/架构/后端源码导读/后端结构.html)与[行动时序图](文档/架构/后端源码导读/一次行动.html)绑定 2026-10-27 的 main；暂不分析前端。想判断结构问题，直接看[证据与评估](文档/架构/后端源码导读/结构评估与验证.md)。


完整版本 v0.5.0：统一雾夜视觉语言与程序化钟楼场景，覆盖昼夜、死亡、私密记录、技能发动与结局的表现，并为系统“减少动效”偏好提供降级；保留世界场景、私密频道、来源可追溯的历史检索、人物陈述整理与可编辑发言建议。身份与人格分离，先过滤权限再检索，密钥始终留在服务器。Issue #63 起，网页可浏览选择四本世界书（雾钟镇、海伯利安、三体、潮汐档案馆），选择会贯通建局持久化、AI/RAG 与主题场景；Issue #64 起，开发阶段 Web 默认开启调试观察，按轮次/阶段/玩家展示模型实际返回的显式说明、工具调用与真实狼队内部对话，关闭后恢复正常信息可见范围。v0.7.0 尚未发布，验收以对应 Issue/PR 为准。

## 运行

需要 Python 3.12+ 与 Node.js 24。在仓库目录：

```bash
python -m venv .venv
.venv/bin/python -m pip install -c requirements-dev.lock -e '.[dev,ai,web,rag]'
npm ci --prefix 前端
npm run build --prefix 前端
cp .env.example .env
chmod 600 .env
# 编辑 .env 填入 DEEPSEEK_API_KEY，勿提交密钥。
.venv/bin/langrensha-web
```

打开 http://127.0.0.1:8000 。选择身份、从容决定，浏览器逐窗口推进其他旅人的行动，可随时暂停；没有游戏倒计时。刷新恢复同一局。札记回答只引用自己有权看到的背景与证词，建议由真人编辑后自行发言。

[完整运行、验收、wheel 与容器部署说明](文档/开发/完整可玩版运行与部署.md)包含可复现命令。完整发行包从 GitHub Actions“前端与发行包检查”下载，已包含网页及 Phaser，无需外部 CDN。CI 使用离线替身；真实 DeepSeek 验收另记。本地部署验收已通过（[#14](https://github.com/nhh37740-glitch/langrensha-agent/issues/14)）；当前没有用户服务器连接资料，不能把本地验收称作线上部署。

[HTTPS 生产部署与备份恢复](文档/开发/HTTPS部署与备份恢复.md)提供 Caddy 入口、私密配置预检及可恢复会话的一致性备份。
